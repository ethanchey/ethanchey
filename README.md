### Other projects

#### [Zoning Document Tracker](link-to-repo)
Townships post and update zoning documents with little notice. This Python prototype downloads documents from three Michigan townships and uses SHA-256 hashes to flag each as new, unchanged, or changed. It also keeps saved copies when a download fails.
